# چک‌لیست قبل از انتشار MIXO6

## ساخت
- [ ] `Validate MIXO6 Windows build` موفق است.
- [ ] `Build and publish MIXO6 (Windows x64)` موفق است.
- [ ] Artifact شامل `MIXO6.exe`، `tools/PresentMon.exe` و `tools/PresentMon-LICENSE.txt` است.
- [ ] `scripts/Download-PresentMon.ps1` فایل رسمی v2.6.0 را دریافت و SHA-256 را تأیید کرده است.

## ویندوز واقعی
- [ ] اجرا/بستن/تغییر اندازه و ناوبری با ماوس و صفحه‌کلید کار می‌کند.
- [ ] فونت Vazirmatn/Estedad پس از نصب و راه‌اندازی مجدد قابل انتخاب است؛ بدون آن fallback خواناست.
- [ ] دمای واقعی CPU و GPU روی دستگاه هدف می‌آید؛ اگر سنسور سازگار نیست، توضیح می‌دهد و عدد جعلی نمی‌دهد.
- [ ] FPS با یک بازی باز، انتخاب فرایند، اجرای PresentMon و (فقط اگر لازم بود) UAC آزمایش می‌شود؛ Artifact باید ابزار را کنار برنامه داشته باشد.
- [ ] DNS apply/reset/flush، کارت Wi-Fi و Ethernet، تأیید UAC و لغو UAC تست می‌شوند.

## احراز هویت و لابی
- [ ] Supabase custom SMTP فعال و `Confirm email` روشن است؛ قالب `Confirm signup` شامل `{{ .Token }}` است.
- [ ] با ایمیل واقعی ثبت‌نام کن، Inbox/Spam را بررسی کن و کد را در برنامه وارد کن.
- [ ] اگر Auth به 500 رسید، Auth Logs و در صورت پیام trigger، Postgres Logs بررسی می‌شود.
- [ ] ورود با ایمیل و نام کاربری؛ بازیابی نشست بعد از restart؛ خروج؛ به‌روزرسانی پروفایل.
- [ ] دو حساب جداگانه: حساب A لابی می‌سازد، حساب B join می‌شود؛ آدرس سرور تا قبل از join و برای کاربر سوم مخفی است؛ لابی پر و بسته، خطاهای قابل فهم دارند.

## امنیت و حریم خصوصی
- [ ] هیچ `sb_secret`، `service_role`، PAT، رمز دیتابیس یا SMTP در سورس، EXE یا Git history نیست.
- [ ] کلید مدیریتی که قبلاً افشا شده بود revoke/rotate شده است.
- [ ] برای دادهٔ کاربران، حریم خصوصی، پشتیبان‌گیری و شرایط سرویس میزبان روشن‌اند.

این فهرست چک‌لیست آزمون است؛ تا وقتی موارد روی ویندوز واقعی انجام نشوند نباید همهٔ قابلیت‌ها «تأییدشده» معرفی شوند.
