# Third-party notices

## PresentMon

MIXO6 uses the official GameTechDev/PresentMon console tool to collect real frame-presentation timing data for FPS display. Version `2.6.0` is fetched from the upstream release during the Windows build, and its SHA-256 is verified by `scripts/Download-PresentMon.ps1`. The license text is fetched from the matching official tag and copied into the release next to the executable. Upstream: https://github.com/GameTechDev/PresentMon.

## Fonts

MIXO6 does not redistribute font files. It detects compatible fonts already installed on Windows. Users can obtain Persian fonts from their official upstream projects: Vazirmatn (https://github.com/rastikerdar/vazirmatn) and Estedad (https://github.com/aminabedi68/Estedad). Each font remains under its upstream license.
